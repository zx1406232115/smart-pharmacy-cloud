# MaixCam Pro 扫码设备接入指南（智能药柜平台）

## 一、整体架构

```
MaixCam Pro（设备端识别条码）
   │  ① WiFi 连接（与电脑同一网络）
   │  ② 同一码连续 3 次命中 → HTTP POST /api/scan/device
   ▼
平台服务端（电脑 192.168.0.100:3001）
   │  查库（是否已建档）→ 推送网页端（储药流程自动带入）+ 返回结果给设备
   ▼
网页端（储药管理页）
   │  条码自动填入「扫码储药」流程 → 已建档直接入库 / 未建档补全信息建档
```

## 二、设备端部署（一次性）

### 1. 检查系统版本
MaixCam Pro 出厂已带 MaixPy 系统。条形码识别 `find_barcodes` 需要 **2024-12-16 之后**的 MaixPy：
- 不确定版本的话，先用 MaixVision 升级系统：
  [官方升级教程](https://wiki.sipeed.com/maixpy/doc/zh/basic/upgrade.html)
  （下载最新系统镜像 → MaixVision 烧录）

### 2. 上传代码
方法 A（推荐）：电脑安装 [MaixVision IDE](https://wiki.sipeed.com/maixpy/doc/zh/basic/maixvision.html) → USB 连接 MaixCam Pro → 打开本项目 `maixcam/main.py` → 点「运行」或保存到设备 `main.py`（开机自启）。

方法 B：把 `main.py` 内容通过 MaixCam 自带的 Web 编辑器上传（设备联网后浏览器访问设备 IP）。

### 3. 修改配置（可选）
默认配置已写死为你的环境（WiFi「1」/ qxy1257889、服务器 192.168.0.100:3001）。
如需修改，两种方式：
- 直接改 `main.py` 顶部的 `WIFI_SSID / WIFI_PASS / SERVER_IP`
- 或在设备 `/root/maixcam_scan.conf` 里写：
  ```
  SERVER_IP=192.168.0.100
  WIFI_SSID=1
  WIFI_PASS=qxy1257889
  ```

## 三、使用流程

1. MaixCam Pro 上电 → 屏幕显示 `ip: 192.168.0.xxx`（自动连 WiFi「1」）
2. 打开平台「设备运维」页 → 顶部 **MaixCam Pro 扫码设备** 卡片显示「在线」（心跳 20 秒一次）
3. 拿药盒条码对准 MaixCam 摄像头：
   - 屏幕出现绿框 + `code: 690xxxx` + `confirm 1/3 → 3/3`
   - 连续 3 次命中后自动上报，屏幕显示服务端返回的「已识别：xxx」或「该条码未建档」
4. 平台「储药管理」页自动弹出对应流程：
   - **已建档** → 显示药品信息 → 填数量 → 确认储药入库
   - **未建档** → 显示建档表单（条码已自动带入）→ 补全名称/形状/尺寸 → 建档 → 再扫一次即可入库

## 四、排障

| 现象 | 处理 |
|---|---|
| 屏幕显示 ip: offline | WiFi 连不上：检查 SSID/密码；也可在 MaixCam 自带「设置」App 里手动连 WiFi（连接后程序会自动复用） |
| 识别不到条码 | 条码需占画面宽度 1/3 以上、静止 1 秒、光线充足；药盒前后移动找清晰距离（MaixCam 是自动对焦，但过近也会糊） |
| upload failed | 电脑防火墙/服务端没开：确认电脑 IP、平台运行中、端口 3001 已放行 |
| 设备卡片显示"等待上报" | 心跳未到：确认同一 WiFi、服务器 IP 正确 |
